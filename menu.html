Git Dasar

Git adalah sistem version control terdistribusi yang digunakan untuk melacak perubahan kode sumber.

  • git init — Inisialisasi repositori baru
  • git add — Menambahkan file ke staging area
  • git commit — Menyimpan perubahan ke repositori
  • git log — Melihat riwayat commit

GitHub

GitHub adalah platform hosting repositori Git berbasis cloud yang memudahkan kolaborasi tim.

  • Membuat dan mengelola repositori online
  • Mengundang kolaborator
  • Melacak isu (issues)

Branching & Merging

Branching memungkinkan pengembangan fitur secara paralel tanpa mengganggu kode utama.

  • git branch nama-branch — Membuat branch baru
  • git checkout nama-branch — Berpindah ke branch
  • git merge nama-branch — Menggabungkan branch

Pull Request

Pull Request adalah mekanisme untuk mengajukan perubahan kode agar ditinjau sebelum digabung ke branch utama.

  • Buat branch baru dan lakukan commit
  • Push ke GitHub
  • Buka Pull Request dari GitHub
  • Minta review dari anggota lain
  • Merge setelah disetujui
